# REPLACE — Code Playground

An interactive Python compiler that runs entirely in the browser — no installation, no sign-up, no server. Part of [REPLACE](https://replaceid.org), a learning initiative building free, interactive tools that make coding easier to learn for everyone.

🔗 **Live:** [code.replaceid.org](https://code.replaceid.org)

---

## What it does

Code Playground lets anyone write and run real Python right in their browser. It's built for beginners, with two ways to learn:

- **Write Code** — a real Python editor with instant output. Edit the sample, run it, and see results immediately (powered by [Pyodide](https://pyodide.org), which runs CPython compiled to WebAssembly).
- **Build Blocks** — a drag-and-drop (and tap-to-place, for mobile) block coding mode. Snap blocks together — variables, print, input, loops, conditions — and watch them turn into real Python code you can run or send to the editor.

## Features

- 🐍 **Real Python in the browser** — full CPython via Pyodide, no backend needed
- 🧩 **Block coding mode** — visual, beginner-friendly, generates real Python
- 📱 **Mobile-friendly** — tap-to-place blocks so it works well on phones
- 🔗 **Shareable code links** — open the playground with pre-filled code via URL (`#code=<base64>`), great for embedding examples in articles
- ⚡ **Instant, offline-capable** — once loaded, runs entirely client-side
- 🎨 **Clean, distraction-free interface** consistent with the REPLACE design system
